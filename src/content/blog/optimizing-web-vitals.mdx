Core Web Vitals represent Google's standardized metrics for user experience quality on the web. A high score isn't just about pride—it directly impacts search engine ranking and user retention.

## The Three Core Pillars

1. **Largest Contentful Paint (LCP)**: Measures perceptual loading speed. Target: `< 2.5s`.
2. **Interaction to Next Paint (INP)**: Measures responsiveness to user taps and clicks. Target: `< 200ms`.
3. **Cumulative Layout Shift (CLS)**: Measures visual stability. Target: `< 0.1`.

### Strategy 1: Font Optimization

Web fonts are a notorious cause of layout shifts and delayed text rendering. With Geist loaded with `font-display: swap` and preconnect links, we ensure text renders immediately without FOIT (Flash of Invisible Text).

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Geist&display=swap" rel="stylesheet">
```

### Strategy 2: Pre-rendering at Build Time

Because this blog is compiled into static HTML files during `npm run build`, every page is ready to be delivered instantly by Vercel's global Anycast edge network.

There is zero database round-trip time, zero cold boot delay, and zero server execution latency.
